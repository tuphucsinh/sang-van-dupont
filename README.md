# Sang Van — St-Dupont Vintage Collection

Landing page premium song ngữ **VI/EN** cho Sang Van — sưu tầm & bảo dưỡng bật lửa S.T. Dupont vintage.

## Tính năng
- Premium vintage đen + vàng gold
- Song ngữ VI/EN (toggle, lưu localStorage)
- Hero full-screen + gallery lightbox
- Responsive mobile

## Chạy local
```bash
python3 -m http.server 8080
```
Mở http://localhost:8080

## Triển khai
Static site — deploy trực tiếp lên Vercel / Netlify / Cloudflare Pages (build command: none, output: repo root).
